# Scalizer Expense Employee Analytic Distribution

Use manual analytic distribution set on employee on expense

## Usage

When an employee is selected on an expense, the analytic distribution is
automatically filled from the **Manual Analytic Distribution** configured on
that employee (see *Scalizer HR Employee Analytic Distribution Manual*).
