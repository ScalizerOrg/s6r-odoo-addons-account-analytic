# Scalizer HR Employee Analytic Distribution Manual

This module adds field manual analytic distribution on employee

## Usage

On the employee form, in the **HR Settings** tab, set the
**Manual Analytic Distribution** field to link a predefined
`account.analytic.distribution.manual` record to the employee.
